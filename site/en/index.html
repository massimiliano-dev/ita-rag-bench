What really matters for RAG on Italian documents

A benchmark that measures the whole retrieval pipeline on laws and decrees from the Italian Official Gazette: text extraction from the PDF, chunking, embeddings and search. Not just the embedding.

Findings

  1. The embedding matters as much as chunking. The parser, on average, slightly less.

    All else equal, moving from e5-base to bge-m3 is worth +9.0 points of recall@5 (95% CI +5.0 to +13.5). Moving from the recursive chunker to the structure-aware one (articles and paragraphs) is worth +8.7 (+4.6 to +13.2). Moving from pypdf to PyMuPDF is worth +6.6 (+3.0 to +10.2). None of the three factors is negligible.

    Check in the timetable:
    • MU·ST·E5
    • MU·ST·M3
    • MU·RC·M3

  2. When parsing fails, it fails completely.

    On Legislative Decree 231/2001, pypdf and Docling return glyph codes instead of text: recall@5 0.00, against 0.90 with PyMuPDF. On Law 241/1990, a scan, pypdf and PyMuPDF score 0.00 and Docling with OCR 0.71. Without these two documents the three parsers are within 4 points of each other. Check first that the extracted text is readable.

    Check in the timetable:
    • PY·FX·M3
    • MU·FX·M3
    • DL·FX·M3

  3. Parsing and chunking set a ceiling before any embedding runs.

    Between 6% and 16% of the reference passages are not contained whole in any chunk, so no retriever can find them. The structure-aware chunker raises the ceiling on single-paragraph questions (0.954 against 0.908) but lowers it on table questions (0.773 against 0.864).

    Check in the timetable:
    • MU·FX
    • MU·ST

  4. BM25 is a hard baseline to beat; hybrid leads, but narrowly.

    BM25 on PyMuPDF with fixed chunks reaches 0.774, level with the best dense configuration (0.780). The highest observed value is hybrid BM25 + bge-m3 on MU·FX, 0.836 (95% CI 0.78 to 0.90): it cannot be told apart from the two configurations that follow it. On table questions BM25 beats dense retrieval (0.73 against 0.50).

    Check in the timetable:
    • MU·FX·BM
    • MU·FX·M3
    • MU·FX·HM

Method and reproducibility

Corpus: 20 official acts downloaded from the Official Gazette and verified with SHA-256. Questions: 150 (135 answerable). Every reference answer is anchored to the official text (document, article, paragraph and passage), not to a chunk, so no chunker is favoured over another.

To run it again:

uv sync --all-extras
uv run itarag corpus fetch
uv run itarag run configs/mvp.yaml
