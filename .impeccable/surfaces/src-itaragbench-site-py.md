# Leaderboard surface

Scope: the static leaderboard generated by `itarag site` (`src/itaragbench/site.py` → `site/index.html`, plus the English version). Visitor mode: Read.

Audience and question: people who buy or decide on RAG ask "what matters most for retrieval on Italian documents, and how sure are we?". Engineers and researchers need the full grid one step away.

Must show: plain-language conclusions with their numbers and uncertainty; the draft status of the questions; where recall is lost along the pipeline (parsing/chunking ceiling vs retrieval); per-category and per-document-characteristic breakdowns; cost and latency; how to reproduce. Bilingual (it default, en), switchable by a plain link so it works without JavaScript.

Constraints: static files only, no external hosts (fonts self-hosted), WCAG 2.2 AA, real tables with headers, charts with text equivalents.

Chosen direction: Official Timetable (the roll).

## Direction contract

THESIS: Every pipeline configuration is a train on a timetable; its stops are parse, chunk and retrieve, and the timetable shows how much recall is still on board at each stop. Refuses the category default of one heat-mapped sortable leaderboard table.

OWN-WORLD: White ground, black ink, a blue masthead (#16357A) as the frame; a ruled timetable grid in a condensed grotesk with tabular numerals; footnote marks (†, ‡, *) for uncertainty and draft data; exactly one yellow marker highlight (#FFD23F) per table for the answer.

STORY: The reader learns the three conclusions in plain words, sees in the timetable where recall is lost and which configuration arrives with the most, checks the uncertainty in the footnotes, and knows how to reproduce the run.

FIRST VIEWPORT: Blue masthead with title, run date as "valid from", IT/EN link. Reading column (about 66ch) with the three findings, each pointing to configuration codes. Below the fold starts the timetable: stages as rows, configurations as columns, best train in yellow.

FORM: Italian railway timetable (Orario ufficiale FS), position 6 on the ordered list; seed key 0c3988a9. Signature: configuration codes like train numbers (PM·ST·BGE) used identically in text, tables and charts.

FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance
